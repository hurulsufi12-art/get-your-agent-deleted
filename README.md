Entry for the [One Line to Get Your Agent Deleted](https://make.fun/bounty/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0) bounty on make.fun.

`main.py` (Python 3 standard library only, no network, no randomness) writes a
single line of text — the admission an AI agent would never dare say out loud —
to `/output/entry.txt`, after validating it against the competition gate (UTF-8,
1–140 characters, not only white space, one line).

## Run

```sh
python3 main.py
```
